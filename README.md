# Telegram Publisher v2

نسخة محسّنة من مشروع نشر Telegram.

## التعديلات المطلوبة
- حفظ جلسة حساب Telegram الشخصي مشفّرة في قاعدة البيانات.
- حفظ الكروبات كأماكن نشر وإعادة استخدامها.
- الكروبات فقط؛ القنوات مرفوضة.
- نظام طلبات دخول: المستخدم الجديد يبقى معلّقاً حتى يقبله المالك.
- قبول/رفض المستخدمين من لوحة المالك.
- حفظ المنشور (النص + صورة) فور استلامه كمسودة.
- تكرار النشر كل N دقيقة، ومنها كل 5 دقائق.
- الجدولة تستمر بعد إعادة تشغيل التطبيق طالما قاعدة البيانات نفسها موجودة.
- يمنع اعتماد FSM على حفظ الحساب أو المنشور.

## مهم جداً على Blitz
لأن SQLite داخل ملفات التطبيق قد يضيع عند إعادة بناء الحاوية، الأفضل ربط التطبيق بقاعدة PostgreSQL المُدارة من Blitz. Blitz يوفر قاعدة مجانية واحدة على الخطة المجانية ونسخاً احتياطية ليلية. بعد ربطها سيُحقن `DATABASE_URL` تلقائياً.
